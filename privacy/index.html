2. 권한 사용 목적

권한 사용 목적
android.permission.CAMERA 사용자가 책 페이지를 직접 촬영해 OCR로 텍스트를 추출하기 위해 사용합니다.
android.permission.INTERNET Google Cloud Text-to-Speech 요청 및 AdMob 광고 요청에 사용합니다.
android.permission.ACCESS_NETWORK_STATE 네트워크 연결 상태를 확인해 광고 또는 Cloud TTS 요청 가능 여부를 판단합니다.

카메라 권한은 사용자가 사진 촬영 기능을 선택한 시점에만 런타임으로 요청됩니다. 갤러리 이미지는 Android Photo Picker를 통해 선택하며, 본 앱은 사진 및 동영상 라이브러리 전체 접근 권한을 요청하지 않습니다.

3. OCR 및 이미지 처리

본 앱은 Google ML Kit의 온디바이스 텍스트 인식 모델을 사용해 한국어 및 영어 OCR을 수행합니다. OCR 입력 이미지와 인식 결과 텍스트는 ML Kit OCR 처리 과정에서 Google 서버로 전송되지 않습니다. 다만 ML Kit는 모델 업데이트, 버그 수정, 호환성 정보 및 API 사용 메트릭 처리를 위해 Google 서버와 통신할 수 있습니다.

촬영 또는 선택된 이미지는 앱의 비공개 저장 영역에 보관되며, 사용자가 책이나 페이지를 삭제하거나 앱 데이터를 삭제하면 함께 삭제됩니다.

4. 데이터 보관 위치 및 기간

본 앱이 생성한 사용자 데이터는 기본적으로 사용자의 기기 내부에만 보관됩니다. 클라우드 동기화, 계정 백업, 개발자 서버 업로드 기능을 제공하지 않습니다.

  • 저장소: 로컬 데이터베이스(Room), 앱 비공개 파일 디렉터리, 로컬 설정 저장소
  • 보관 기간: 사용자가 책/페이지를 삭제하거나 앱 데이터를 삭제하거나 앱을 제거할 때까지
  • Cloud TTS 오디오 캐시는 동일 텍스트 재생 시 네트워크 요청을 줄이기 위한 용도로만 사용됩니다.

5. 제3자 서비스 및 외부 전송

Google Cloud Text-to-Speech

사용자가 Cloud TTS 엔진으로 책을 저장, 재생, 재생성할 때 읽어 주기를 요청한 동화책 텍스트와 선택한 음성 합성 설정이 Google LLC에 전송될 수 있습니다. 사용자가 Android 기기 내장 TTS 엔진을 선택한 경우 책 텍스트는 Cloud TTS로 전송되지 않습니다.

참고: Google Cloud TTS 데이터 로깅 문서

Google AdMob / Google Mobile Ads SDK

본 앱은 앱 내 광고를 위해 Google AdMob SDK를 포함합니다. 광고가 로드되거나 표시될 때 Google Mobile Ads SDK는 광고 제공, 분석, 부정행위 방지 목적을 위해 IP 주소, 사용자 상호작용 정보, 진단 정보, 기기 및 계정 식별자(Android 광고 ID 등)를 처리할 수 있습니다. 모든 AdMob 전송 데이터는 전송 중 암호화됩니다.

참고: Google Mobile Ads SDK 데이터 공개 요구사항, Google 광고 정책

Google ML Kit 텍스트 인식

OCR은 온디바이스 ML Kit 텍스트 인식 모델을 사용합니다. 입력 이미지와 OCR 결과 텍스트는 Google 서버로 전송되지 않지만, ML Kit는 모델 업데이트 및 API 사용 메트릭 처리를 위해 Google 서버와 통신할 수 있습니다.

참고: ML Kit 약관 및 개인정보 안내

6. 데이터 삭제 방법

사용자는 언제든지 본 앱이 저장한 데이터를 다음 방법으로 삭제할 수 있습니다.

  • 앱 내에서 책 또는 페이지를 삭제합니다.
  • Android 설정에서 LazyDaddy 앱의 저장공간 데이터를 삭제합니다.
  • 앱을 제거합니다. 이 경우 기기에 저장된 앱 데이터가 함께 삭제됩니다.
  • Android 설정의 개인정보 보호 또는 Google 광고 메뉴에서 광고 ID를 삭제하거나 재설정할 수 있습니다.

본 앱은 개발자 서버에 사용자 데이터를 보관하지 않으므로, 서버 데이터 삭제를 위해 별도 요청할 필요가 없습니다. 문의가 필요한 경우 아래 연락처로 요청해 주세요.

Privacy Policy - English Summary

LazyDaddy is a storybook reader app for parents and guardians. It lets users photograph or select book pages, extract Korean or English text with on-device OCR, and play the text aloud with Android built-in TTS or Google Cloud Text-to-Speech.

  • The app does not provide accounts, login, cloud sync, or developer-server backup.
  • Camera images and Photo Picker images are stored in the app's private storage and are not uploaded by the app.
  • OCR text, edited text, book titles, page order, selected OCR language, app language, and TTS settings are stored locally on the device.
  • Google Cloud Text-to-Speech receives only the text and voice synthesis settings needed to generate speech when the Cloud TTS engine is used.
  • Google ML Kit OCR runs on-device. Input images and OCR results are not sent to Google servers.
  • Google AdMob / Google Mobile Ads SDK may process advertising, diagnostics, and device identifier data when ads are loaded or shown.
  • Users can delete data by deleting books or pages in the app, clearing app data in Android Settings, or uninstalling the app.
  • The app is intended for parents or guardians, not for direct use by children under 13.
